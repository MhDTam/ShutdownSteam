# Changelog

## 1.0.0

- Portable Windows executable with the glass dashboard and transparent emblem.
- Local Steam library discovery and selected-game download monitoring.
- Local game thumbnails in the selected field and dropdown, with a fallback icon.
- Test notification, shutdown, restart, hibernate, and lock actions.
- Monitoring settings, in-memory logs, and shutdown cancellation.
- GitHub Actions build verification, release archive, and SHA-256 checksums.
