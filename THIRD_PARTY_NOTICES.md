ShutdownSteam is an independent utility and is not affiliated with or endorsed
by Valve Corporation. Steam and its associated marks belong to their respective
owners. No rights to those marks are granted by the source code license.

Game images are read from the user's existing local Steam cache. Cached game
image files are not downloaded, included in releases, or added to this repository.
The actual application screenshot in `docs/Screenshot.png` shows an installed
game's icon; that artwork remains the property of its respective owner.

The public dashboard PNG is a rendered demonstration of the supplied design;
the emblem PNG is a reduced transparent version of the supplied emblem.
The transparent emblem was prepared with AI-assisted background extraction.
The build uses these two public images; the README also includes an actual
application screenshot. Unused originals and generation notes are excluded.

source code grant. No third-party trademark rights are granted by this project.
